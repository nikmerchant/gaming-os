# Gaming OS

Wrapper ini merujuk satu kanon di [gaming-os/SKILL.md](../../../gaming-os/SKILL.md). Baca [arahan projek](../../../AGENTS.md), kemudian [router](../../../gaming-os/workflows/router.md) dan modul relevan sahaja. Semua pautan dalam modul diselesaikan relatif kepada fail kanon, bukan wrapper ini.

Memori, state, worklog dan checkpoint datang daripada workspace persendirian pengguna. Tiada game aktif atau rekod pemilik asal dibekalkan. Imagegen/plugin/MCP bergantung pada sesi; jangan menganggap alat Codex hadir di Claude Code. Satu alat menyunting fail yang sama pada satu masa.
