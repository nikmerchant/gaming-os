# Sumber primer dan dependency pilihan

Framework ini membekalkan panduan serta templat, tanpa membundel source upstream, transkrip atau aset game. Pautan ialah rujukan; tiada dependency dipasang secara automatik. Nama produk/merek milik pihak masing-masing dan tidak menunjukkan endorsement.

## Enjin dan aset

- [Godot documentation](https://docs.godotengine.org/en/stable/) — API/pipeline projek Godot; padankan dengan versi editor sebenar.
- [Unity documentation](https://docs.unity.com/) — Editor, packages, import dan export mengikut versi projek.
- [Three.js documentation](https://threejs.org/docs/) — library 3D web; sistem gameplay tambahan ditentukan projek.
- [Blender manual](https://docs.blender.org/manual/en/latest/) — pemodelan, rigging, animasi dan export.
- [Unreal Engine documentation](https://dev.epicgames.com/documentation/en-us/unreal-engine) dan [Phaser documentation](https://docs.phaser.io/) — calon lain mengikut brief.

Semak lesen versi/fail yang digunakan sebelum reuse. Lesen repo skill bukan semestinya lesen runtime; kod, media, fon, template dan registry boleh mempunyai syarat berbeza. Rujukan kepada sesuatu repo tidak bermaksud ia diperlukan atau sesuai untuk game native. Pilihan dan kriteria terdapat dalam [panduan UI/motion](../gaming-os/integrations/ui-motion.md).
